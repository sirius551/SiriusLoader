# Sirius Loader MCP

Локальный MCP-сервер для Sirius Loader. MCP-клиент подключается к Python-процессу через **stdio**, а Roblox executor связывается с локальным HTTP-мостом на `127.0.0.1:8765`.

## Возможности

- статус подключения, игрока, PlaceId, JobId, здоровье и координаты;
- список зарегистрированных переключателей, слайдеров и действий;
- включение/выключение зарегистрированных переключателей;
- запуск существующих кнопок Loader по их точным идентификаторам;
- создание Lua-файлов в папке `scripts/` (без автоматического запуска);
- выполнение Lua в активном executor через отдельный инструмент с обязательным `confirm_risk=true`;
- создание скриншота рабочего стола в папке `screenshots/`;
- чтение локального журнала.

## Установка

1. Установи Python 3.11 или новее.
2. В этой папке выполни:

   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   py server.py
   ```

3. При первом запуске сервер создаст `Sirius_MCP_Token.txt`. Скопируй этот файл в рабочую папку executor, откуда Sirius Loader может вызвать `readfile("Sirius_MCP_Token.txt")`. Не публикуй токен и не отправляй его в чат.
4. Запусти Roblox и Sirius Loader. В Output/консоли должно появиться уведомление **Sirius MCP — Локальный мост активен**.
5. Добавь MCP-сервер в конфигурацию своего MCP-клиента как локальный stdio-процесс:

   ```json
   {
     "mcpServers": {
       "sirius-loader": {
         "command": "C:\\path\\to\\Sirius\\MCP\\.venv\\Scripts\\python.exe",
         "args": ["C:\\path\\to\\Sirius\\MCP\\server.py"]
       }
     }
   }
   ```

   Замени пути на реальные пути на своём компьютере. Перезапусти MCP-клиент после изменения конфигурации.

## Инструменты

- `sirius_connection_status`
- `sirius_get_status`
- `sirius_list_controls`
- `sirius_set_toggle(control_id, enabled)`
- `sirius_run_action(action_id)`
- `sirius_create_lua_script(filename, code)`
- `sirius_execute_lua(code, confirm_risk)`
- `sirius_capture_screenshot()`
- `sirius_read_recent_logs(max_lines)`

Идентификаторы действий имеют вид `ИмяВкладки/НазваниеКнопки`, переключатели — `ИмяВкладки/НазваниеПереключателя`. Сначала вызови `sirius_list_controls`, чтобы получить точные ID.

## Предупреждение о выполнении кода

`sirius_execute_lua` исполняет переданный Lua-код **внутри текущего Roblox executor**. Код может менять состояние игры, вызывать доступные executor API, загружать другие скрипты и завершать работу Loader. Ограничения модели ИИ не являются песочницей и не гарантируют безопасность кода. Проверяй содержимое каждого скрипта и разрешай выполнение только после явного подтверждения пользователя. Инструмент требует `confirm_risk=true`; это подтверждение должно быть получено от пользователя для конкретного кода, а не предполагаться автоматически.

## Безопасность

- HTTP bridge слушает только `127.0.0.1`, не открывай порт 8765 наружу.
- Токен — локальный секрет. Не коммить его и не отправляй в переписку.
- MCP-инструменты доступны тому MCP-клиенту, который запустил этот процесс. Не подключай неизвестные клиенты.
- Скриншот захватывает весь основной экран, поэтому перед отправкой проверь, что на нём нет личных данных.
- Для остановки моста заверши процесс `server.py`. Loader без MCP продолжит работать.

## Ограничения

- Для связи нужен executor с HTTP request API, разрешающим запросы к localhost, и файловым API `readfile`.
- Скриншот захватывается на стороне компьютера Python-сервером, а не Roblox.
- FE/серверные действия ограничены тем, что сама игра разрешает клиенту. MCP не превращает локальные изменения в серверные.
